# Gestão de Contatos

Sistema de gerenciamento de contatos desenvolvido com PHP e MySQL, com o objetivo de praticar e demonstrar conceitos de desenvolvimento web, operações CRUD e integração com banco de dados.

## 🎯 Objetivo

Evoluir um sistema de cadastro de contatos para uma aplicação completa de gerenciamento, permitindo administrar informações de forma simples, organizada e segura.

## 🚀 Funcionalidades

- [x] Cadastro de contatos
- [x] Listagem de contatos
- [x] Pesquisa por nome ou e-mail
- [x] Visualização individual de contatos
- [ ] Edição de contatos cadastrados
- [ ] Atualização de informações
- [ ] Exclusão de contatos com confirmação

## 🔧 Como executar o projeto

1. Instale o XAMPP.
2. Inicie os serviços Apache e MySQL.
3. Coloque a pasta do projeto dentro do diretório `htdocs`.
4. Crie o banco de dados `lista_contatos` no phpMyAdmin.
5. Configure a conexão com o banco no arquivo `config/database.php`.
6. Importe ou crie a tabela `contatos`.
7. Acesse o projeto pelo navegador:

```text
http://localhost/gestao-de-contatos/
```
